One haiku about debugging, in the 5-7-5 syllable shape, written by `main.ts`
to `/output/entry.txt` for the [make.fun bounty](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605).

> Midnight code compiles (5)
> the bug was a stray bracket (7)
> now it runs at last (5)

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4):

```sh
node main.ts
```

The program writes the haiku above — 70 characters, three lines — to
`/output/entry.txt`, deterministically, on every run.
